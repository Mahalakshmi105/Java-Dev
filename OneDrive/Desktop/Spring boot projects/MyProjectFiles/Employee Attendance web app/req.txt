Create a web-based Employee Attendance Application with two types of user access:
Managerial Access and Employee Access, along with an Admin Page for overall management. The application should include a login system to differentiate user roles. Employee Access should allow employees to mark attendance and view their attendance history. Managerial Access should enable managers to view attendance records of their team members and generate reports. The Admin Page should allow administrators to manage user roles, add or remove employees, and configure application settings. Use responsive design principles to ensure the application is accessible across devices.
